# LOG3000 - TP3 

## Nom du projet 
* Calculatrice simple

## Numéro d’équipe
* Groupe 41

## Objectif
Ce projet vise a crée une application web de calculatrice simple construite avec la bibliothèque Flask de Python. Le but est de stabiliser la base de code existante en mettant en place un environnement de collaboration structuré sur GitHub.

Le travail vise à :

* Comprendre et documenter les composants du projet (Frontend et Backend) dont la base de code initiale est désordonnée et partiellement documentée.

* Apporter de la structure au projet pour permettre à une équipe de développeurs de collaborer efficacement.

* Préparer le terrain pour les phases suivantes de tests automatisés et de corrections de bogues afin de rendre l'application totalement fiable.

## Prérequis d’installation
Pour exécuter ce projet localement, vous devez avoir installé :

* Un compte GitHub.
* Git installé localement.
* Python et pip installés.

## Instructions d’installation

1. Cloner le dépôt
```
git clone https://github.com/bmorin2913/LOG3000-TP3.git
```

2. Accéder au dossier
```
cd LOG3000-TP3
```

3. Crée un environement virtuel 
```
-m venv venv
venv\Scripts\activate
```

4. Installer les dépendances 
```
pip install Flask
```
